**Project Overview:**
This project applies the complete machine learning workflow to predict student pass/fail outcomes using the UCI Student Performance dataset. The workflow includes data cleaning, EDA, feature engineering, and the development of three models (Logistic Regression, Random Forest, and a Neural Network).

**How to run:**
1. Ensure `student-por.csv` is in the same directory.
2. Open `DS471.ipynb` in Jupyter or Colab and run all cells.
